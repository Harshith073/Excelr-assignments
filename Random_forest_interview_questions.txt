Interview Questions

1. Explain Bagging and Boosting methods. How are they different from each other?

Bagging and boosting are both ensemble learning methods that combine multiple weak models to create a single strong model, but they do so in very different ways. Bagging, which stands for bootstrap aggregating, trains multiple models (usually decision trees) in parallel on different random subsets of the training data created with replacement. Once trained, the final prediction is made by averaging the outputs for regression or taking a majority vote for classification, which helps reduce model variance and overfitting. Boosting, on the other hand, trains models sequentially rather than in parallel, where each new model is trained to correct the specific errors made by the previous models in the sequence. It does this by increasing the weights of misclassified instances so the next model focuses more on them, which is highly effective at reducing bias but makes the model more susceptible to overfitting if the data is noisy.

2. Explain how to handle imbalance in the data.

Handling imbalanced datasets is important because standard models tend to be biased towards predicting the majority class. One common approach is resampling, which involves either oversampling the minority class (using techniques like SMOTE to generate synthetic examples) or undersampling the majority class to balance the class distribution, though undersampling risks losing valuable information. Another effective method is adjusting the model's internal parameters, such as using class weights to penalize misclassifications of the minority class more heavily during training, which is a built-in feature in many algorithms like Random Forests. Finally, it is crucial to use appropriate evaluation metrics; instead of relying on overall accuracy, which can be misleadingly high, we should focus on metrics like precision, recall, F1-score, and the area under the ROC curve (ROC-AUC) to get a true picture of how well the model is performing on the minority class.
