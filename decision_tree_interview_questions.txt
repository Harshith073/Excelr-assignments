Interview Questions

1. What are some common hyperparameters of decision tree models, and how do they affect the model's performance?

Some of the most common hyperparameters for decision trees include max_depth, min_samples_split, min_samples_leaf, and max_features. The max_depth parameter controls how deep the tree can grow; setting it too high usually leads to overfitting because the tree learns the training noise, while setting it too low can underfit the data. The min_samples_split and min_samples_leaf parameters determine the minimum number of samples required to split an internal node or to be at a leaf node, respectively; increasing these values acts as regularization, preventing the tree from creating highly specific leaves that only apply to one or two samples. Finally, max_features limits the number of features considered for splits at each node, which introduces randomness and is especially useful for reducing variance when ensemble methods are used.

2. What is the difference between the Label encoding and One-hot encoding?

Label encoding and one-hot encoding are two different ways to convert categorical data into a numerical format that machine learning algorithms can understand. Label encoding assigns a unique integer to each category, which works well for ordinal data where the categories have an inherent order, but it can mislead models into assuming a mathematical relationship or order where none exists. One-hot encoding, on the other hand, creates a new binary column for each category in the feature, where a 1 represents the presence of that category and 0 represents its absence. This avoids implying any artificial ordering, but it can significantly increase the dimensionality of the dataset if there are many unique categories.
